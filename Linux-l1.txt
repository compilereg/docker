	Absolute path: the path always start with /
	Relative path: The path always does not start with /
	/var/log/messages: absolute
	log/messages: relative if you are in /var
	..: parent
	IF you are on bob, 
		../alice/messages
	1-pwd: Print Working Directory:Absolute
	2-ls: List the directory contents; Read permission on directory
		ls: List current directory
		ls /etc/: List /etc directory content
		ls -l: Read/and Execute permissions on directory
		1st: col: 10 characters
			1character: -(regular file), d(directory),l(link),c(Character device),b(Block device)
			rwx: r: read, w:write, x: execute
			---	: owner
			---	: group
			---	: other
			Example:-r--r----- compiler compiler 			mydatafile
			Any user tries to access mydatafile.
			1-User is owner ? yes, 1st 3 characters
			2-User member in group? yes, 2nd 3 characters.
			3-Else, 3rd 3 characters.
		3rd: col	: owner
		4th: col	: group
		Permissions can be set from root/or owner
		ls -ld: Directory
